# CIS 226 WSL Portfolio

This portfolio records Linux work completed in Ubuntu on Windows Subsystem for Linux for CIS 226. The project demonstrates files, permissions, users, processes, cron backups, I/O redirection, and Git.

## Contents

- `weeks-01-07/week05-permissions.md`: permission tests and their observed results
- `week08-rehearsal/rehearsal_summary.txt`: the actual six-block rehearsal summary

The project owner and scheduled backup user is labstudent. Privileged setup and cleanup were performed through WSL's root account; labstudent was not granted administrator access. The temporary intern account, project group, and cron entry were removed after testing.
